## Nextstrain Analysis
Based on the [pre-2027 Nextstrain EV-D68 analysis pipeline](https://github.com/nextstrain/enterovirus_d68/releases/tag/1.2), modified for the analysis of 2025 EV-D68 sequences in Europe, as used in **TODO: LINK MANUSCRIPT HERE**.

The pipeline can be used to generate VP1, partial-VP1, and full-genome runs, but here was used to generate a special run - VP1-only with a threshold of >=700bp for sequences prior up to 2023, and >=300bp for sequences from 2024-2025.

Note as this is based on the older Nextstrain pipeline and includes custom steps it is not recommended to use it for creating a new Nextstrain build, but is provided for reproducibility and transparency.

Note that analysis will be incomplete and will not run correctly to the inability to share raw age data and sequences used in the analyses. The local version used for the manuscript included raw age data, and all sequences are now available on Genbank (see manuscript).

For notes on running such an analysis, see [the full Nextstrain readme](https://github.com/nextstrain/enterovirus_d68/releases/tag/1.2).


## Scripts used for processing, figures, and analyses

Scripts are in `analysis_scripts` folder.

1. **`raw_data_to_correct_format.R`** - Used to bundle data from collaborators in different fasta and CSV files to compile the final set of data, as well as ensure all sequence names match between fasta & CSV, which are wastewater vs clinical, which have age, and some other checks. Output from this file is the study-generated dataset input for the Nextstrain build as well as some other analyses.

2. **Nextstrain analysis** - All available data was downloaded from NCBI Virus to form a starting dataset for the Nextstrain build, combined with the 2025 data, from the files generated by the first script. This should be run second as creates the 'all data' files that can be used for other analyses.

3. **`EVD68 graph_to github.ipynb`** - Jupyter notebook used to collect summarized statistics of denominators, case data, and wastewater data, to generate Figure 1 (testing and results of EV-D68 per month) and Figure 2 (cases by age group).

4. **`age_analysis.r`** - Reads in data from Nextstrain build and the 2025 data that was excluded from the build (for being too short, etc), and runs the Fisher tests to look at adult vs child cases per year. Also produces Supp Fig S3 (child vs adult cases per year).

5. **`age_clade_regression.r`** - Builds on the data pulled together from `age_analysis.r` and plots a correlation of subgenogroup vs age. (Supp Fig S4)

6. **`plotSequencesByGenogroupSeason.py1`** - Reads in data similarly to the above, but builds a plot showing subgenotype distribution by year, along with the number of sequences per year (Fig 4).

7. **`add2025asColorby.py`** and **`recolor_study_tips_manuFig.py`** - Manipulate the Nextstrain JSON and SVG format to allow recoloring of the outline of the samples resulting from this study in 2025. First run `add2025asColorby.py` on the resulting Nextstrain JSON (specify the most recent run date), and then open the resulting JSON in Auspice. No need to *use* the colorby - set up the figure as you'd like for the manuscript - zoom and size. Export as SVG, and then use the `recolor_study_tips_manuFig.py` code to recolor the tips in the resulting SVG. Produces the coloring in B and C of Fig 3.
